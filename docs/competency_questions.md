# FLU 2.0 — Competency Questions

**Date:** 2026-10-19  
**Status:** Priority questions for the Core ontology

These questions define what the FLU 2.0 Core should be able to answer. They are influenza-generic unless noted.

## Lifecycle process questions

1. What are the major processes in the influenza A virus lifecycle, from attachment to release of progeny?
2. What is the temporal order of these processes?
3. Which viral and host entities participate in each process?
4. In which cellular compartments does each process occur?

## Entity questions

5. What are the canonical influenza A proteins and their primary roles?
6. Which accessory proteins (PB1-F2, PB1-N40, PA-X) are recognized, and what is the evidence strength for each?
7. What host factors are required for nuclear import of vRNPs?

## Quantitative / evidence questions

8. What is the measured timing of nuclear vRNP import in A549 cells infected with PR8?
9. Which simulation parameters have been fitted to A549 + PR8 data?
10. What is the provenance and uncertainty level for each major process?

## Scope questions

11. Does the ontology distinguish generic influenza A biology from strain- or cell-line-specific observations?
12. Can the Core be used without importing the full OBO stack?

These questions guided the design of the self-contained MIREOT Core and the Alpha module.
